# Docs

## Why

Work produces documents that need keeping -- contracts, briefs, reports, meeting notes. Without a conventional home, they scatter across folders or get lost. Docs/ is the filing cabinet for this scope.

## How

Store or reference documents with a longer shelf life than inbox/ items. Files here are meant to be found again.

### Store-or-point

- **Stored:** Files saved directly (markdown, PDFs, exported documents).
- **Pointer:** "Documents are in Google Drive at [URL]. This folder tracks what's there."

### Boundaries

- Docs is for *keeping*. Fleeting thoughts go in inbox/. Active tasks go in todo/. Background narratives go in context/. Structured records go in databases/.
- No prescribed filing system. Flat or nested, whatever suits the scope's volume.

## What an agent should do

1. Save documents here when asked to file, capture, or store something for this scope.
2. Name files descriptively so they're findable without a search tool.
3. When the folder is a pointer, use the described connector to access documents.
