# Ontology

The shared vocabulary for this scope. Definitions of what terms and concepts mean here, so everyone (human and AI) works from the same understanding.

In the ExFu base, this defines the structural vocabulary of the substrate: what scopes are, how folders are organised, what librarians do. In your own scopes, this is where you'd put domain-specific definitions -- your team's jargon, your project's terminology, anything that needs to be explicit rather than assumed.
