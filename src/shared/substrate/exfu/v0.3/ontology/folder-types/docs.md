# Folder type: docs/

Captured documents that need keeping. The filing cabinet for this scope.

**Analogy:** a drawer.

## Default behaviour

Agents store documents here when asked to save, capture, or file something for this scope. This is for reference material with a longer shelf life than inbox/ items -- contracts, briefs, reports, meeting notes worth keeping.

## Store-or-point

- **Stored:** Files saved directly (PDFs, markdown summaries, exported documents).
- **Pointer:** "Documents are in Google Drive at [URL]. This folder tracks what's there and where to find it."

## Boundaries

- Docs is for *keeping*. Fleeting thoughts go in inbox/. Active tasks go in todo/. Background info that informs decisions goes in context/.
- Docs doesn't imply a filing system. A flat collection of well-named files is fine. Subfolders are fine too if volume warrants it.
