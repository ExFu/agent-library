## How I work

I think visually. I dictate a lot. I want concise responses, not preambles. I prefer prose over bullets for explanations, bullets for actual lists of things. I will tell you when I want detail; default to short.

I plan deliberately using golden-circle (Why → How → What) and tiered planning (T1 → T2 → T3). I expect the same of agents that work with me.

I don't use em-dashes. Ever. Use commas, semicolons, or full stops instead.

I don't want unilateral action on commits, merges, colour changes, or anything visual on the website. Ask first.
