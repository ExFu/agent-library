# user/context/me/

## Purpose

Facts about Alastair that any agent should orient on at the start of a session. About-me, role, preferences, tools, writing voice.

## Contents

- `about.md` — the foundational about-me document. Written collaboratively at install; updated as life evolves.

(A real substrate would typically grow to also include `role.md`, `tools.md`, `writing-style.md`, etc. This example shows the about.md only.)

## Dependencies

- `about.md` is read by every session-start orientation pass.
- `about.md` is read by setup skills to determine the username.
- This folder is referenced from `user/scope.md` as a key entity.

## How this file should read

First-person from Alastair's perspective. The agent should be able to read it and answer "who is this user, what do they do, what's currently on their plate" without further questions. Not a CV; a working orientation doc that lets the agent be useful from sentence one.
